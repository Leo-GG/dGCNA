# Robustness of correlation-based gene networks in single-cell data

This repository contains the code and analysis notebooks for the study evaluating the robustness of the differential gene co-expression network analysis (dGCNA) method applied to single-cell RNA-seq data from T2D and non-T2D human pancreatic islets.

## Repository structure

```
├── run_dgcna_correlation.py   # Python reimplementation of dGCNA
├── run_dgcna_R.R              # R script to run the original dGCNA on exported data
├── code/
│   ├── basic_functions.R      # Original R functions from Martinez-Lopez et al.
│   └── network_functions.R    # Original R network utilities
├── tests/
│   └── test_dgcna_lmm.py     # Unit tests for the Python LMM solver and pipeline components
├── 1–9 Notebooks              # Reproducible analysis (see below)
├── Supp_Verify_R.ipynb        # Cross-validation of Python vs R implementation
```

## Python dGCNA implementation

dGCNA is implemented in **`run_dgcna_correlation.py`**. It reproduces the original R method: per-gene intercept-only linear mixed models (LMM) with donor as a random effect, fitted separately within each condition via profiled REML, followed by Pearson correlation of the residuals, differential network construction, and bootstrap donor-permutation filtering.

### Requirements

- Python ≥ 3.9
- numpy, pandas, scipy, tqdm, scanpy

### Usage

```python
import scanpy as sc
from run_dgcna_correlation import run_dgcna_analysis

adata = sc.read_loom("Integrated_betas.loom")
results = run_dgcna_analysis(
    adata,
    genes=gene_list,          # list of gene names to analyse
    disease_col="Disease",
    t2d_value="T2D",
    ctrl_value="normal",
    donor_col="Donor",
    n_bootstrap=512,
    threshold=0.975,
)
```

The returned dictionary contains:
- `residuals` — LMM residuals (cells × genes DataFrame)
- `corr_t2d`, `corr_ctrl` — per-group Pearson correlation matrices
- `diff_net` — differential network (T2D − control)
- `mask` — bootstrap frequency matrix
- `filtered_net` — thresholded differential network

Input data must already be on the log₂(RPKM + 1) scale and filtered for expressed genes. The `.X` matrix should be dense or sparse, with `.obs` containing donor and disease annotations.

### Unit tests

```bash
python -m pytest tests/test_dgcna_lmm.py -v
```

## R implementation (`run_dgcna_R.R`)

**`run_dgcna_R.R`** runs the original R dGCNA pipeline (using `lme4::lmer` and the functions in `code/basic_functions.R`) on data exported from Python. This is used to cross-validate the Python reimplementation against the original R code.

### Requirements

- R with the `lme4` package

### Input

Two CSV files (generated by `Supp_Verify_R.ipynb`):

- **`Expr_beta.csv`** — expression matrix (cells × genes), log₂(RPKM + 1) scale, with row and column names
- **`Obs_beta.csv`** — cell metadata with columns `Donor` and `Disease` (categories: `T2D`, `normal`)

### Usage

```r
Rscript run_dgcna_R.R
```

### Output

| File | Description |
|---|---|
| `R_residuals_T2D.csv` | LMM residuals for T2D group (cells × genes) |
| `R_residuals_normal.csv` | LMM residuals for normal group (cells × genes) |
| `R_corr_T2D.csv` | Pearson correlation matrix, T2D |
| `R_corr_normal.csv` | Pearson correlation matrix, normal |
| `R_diff_net.csv` | Differential network (T2D − normal) |

### Cross-validation

The notebook **`Supp_Verify_R.ipynb`** exports the input CSVs, loads the R outputs, and compares them element-wise against the Python results. Across all 664 NDCG genes, the maximum absolute differences are:

| Quantity | Max absolute difference |
|---|---|
| Residuals | 2.0 × 10⁻⁴ |
| Control correlations | 3.7 × 10⁻⁶ |
| T2D correlations | 2.5 × 10⁻⁷ |
| Differential network | 3.7 × 10⁻⁶ |

## Analysis notebooks

The numbered notebooks reproduce all analyses in the paper. Run them in order:

| Notebook | Description |
|---|---|
| `1_Generate_loom_files.ipynb` | Load raw RPKM data for datasets 1 (GSE153855) and 2 (GSE214517), filter genes, log-transform, identify cell types, and export loom files |
| `2_Generate_integrated.ipynb` | Integrate the two datasets with BBKNN, filter beta cells (≥30 cells/donor), and export `Integrated_betas.loom` |
| `2a_Integrated_logFC.ipynb` | Compute per-gene log₂ fold changes (T2D vs control) on the integrated beta cells |
| `3_Correlations_on_integrated_fast.ipynb` | Run the full dGCNA pipeline on integrated beta cells and characterise the resulting network |
| `4_Resampling_stability.ipynb` | Cell-subsampling stability analysis of correlations and differential correlations |
| `5_Example_pair.ipynb` | Detailed visualisation of the CEBPG–ARL15 edge (per-donor correlations, scatterplots, subsampling stability) |
| `6_Correlations_CTR_CTR.ipynb` | Specificity test: dGCNA on control donors only (random cell split and exhaustive 4-vs-4 donor partitions) |
| `7_Generate_loom_Raw_and_Pseudo_bulk.ipynb` | Generate raw-count loom files and pseudobulk expression profiles for differential expression analysis on dataset 1 |
| `8_DE_pseudobulk_dataset1.ipynb` | Pseudobulk differential expression analysis with pyDESeq2 |
| `9_Source_Data.ipynb` | Statistical re-analysis of the original paper's source data (siRNA knockdowns, insulin secretion assays, immunofluorescence) |
